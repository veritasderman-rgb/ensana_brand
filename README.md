# Ensana Brand Manual

Machine-readable brand manual for **Ensana Health Spa Hotels**, compiled from the official 2018 brand package (guidelines, colours, logo & naming systematic, imagery guidelines, brochure toolkits, email signature manual).

**Primary file:** [`ENSANA-BRAND-MANUAL.md`](./ENSANA-BRAND-MANUAL.md)

## Purpose

This repository is intended to be consumed by **AI design assistants** (e.g. Claude as a designer). The manual is structured as a single Markdown file with:

- Logo and naming system (brand / cluster / hotel level)
- Full primary and secondary colour specification (Pantone · CMYK · RGB · HEX)
- Typography scale (Branding by Latinotype)
- Imagery tonality, types and dos/don'ts
- Tone of voice & recurring copy
- Application templates (business cards, email signatures, brochures, web, signage)
- A YAML quick-reference block that can be dropped straight into a prompt

## How to use with Claude

Either:

1. Point Claude at the raw URL of [`ENSANA-BRAND-MANUAL.md`](./ENSANA-BRAND-MANUAL.md) and tell it to follow the rules when producing Ensana visuals; or
2. Copy the **§8 Design system quick-reference** YAML block into your prompt for a lightweight context.
